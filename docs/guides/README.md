# Quark guides

[中文](README-cn.md) · [Back to project README](../../README.md) · [API index](https://quarks.cc/doc/)

These guides explain how to use Quark features in application code. They
complement the generated API reference, which documents individual modules,
classes, properties, and methods.

- [View layout and styles](VIEW_STYLE.md): the public View hierarchy, JSX
  layout, class selectors, pseudo states, and style transitions.
- [Actions and keyframes](ACTIONS.md): action composition, keyframe animation,
  playback control, and action events.

Every guide has an English file and a Chinese `-cn.md` counterpart. The API
documentation generator publishes this directory together with the generated
module reference.
